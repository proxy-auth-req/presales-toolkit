# Sprinklr compliance artefacts (trust.sprinklr.com)

Vetted, customer-shareable documents available from the Sprinklr Trust Portal. Ask the
user to pull the relevant ones early — an approved artefact beats bespoke prose
(playbook §18), and several answer evidence demands outright.

The user retrieves these; this skill has no portal access.

## Usually worth pulling on a security-heavy bid

| Document | What it answers |
|---|---|
| **ISO/IEC 27001 certificate** | Certificate number, issuing body, validity dates, scope statement. Several criteria demand exactly this pair — certificate plus scope statement. |
| **SOC 3 attestation** | The publicly distributable counterpart to SOC 2 Type 2. Where it covers comparable scope it takes evidence lines out of NDA-gating, which matters on scored criteria. Check which Trust Services Criteria are in scope. |
| **Data Privacy Program / Data Protection Brochure** | TOM description, appointed DPO, subprocessor framework with periodic re-assessment, breach-notification commitment. The strongest filler for Art. 32 gaps. |
| **GDPR** | Data-protection criteria. |
| **White Paper on International Data Transfers** | Transfer mechanisms, subprocessor processing locations, government-access handling. |
| **Transparent and Lawful Processing** | Controller/processor allocation, processing-on-instruction. |
| **EU AI Act** (Compliance and AI entries) | AI governance criteria. |
| **Responsible AI Framework**, **Responsible AI Statement**, **Overview of AI at Sprinklr** | AI governance depth. |
| **DORA** | Points at the Financial Sector Addendum, which carries Art. 30 audit-and-inspection language. |
| **EU-US DPF** | Transfer mechanism where US access is in scope. |
| **Cyber Insurance** | Tenders that ask for insurance evidence. |

## Usually not relevant to EU/DACH bids

**CCPA, CPRA, VCDPA, LGPD** — wrong jurisdictions. **VPAT** — accessibility, outside a
security catalogue. **TISAX** — automotive. **BitSight**, **Scorecard** — external
ratings, not policy documents.

## Three practical warnings

**Read every document against the answers before attaching it.** Titles mislead. On one
bid, three of seven candidates would have damaged the submission — see playbook §18 for
the specifics. The mapping pass exists as much to find those as to shorten anything.

**Trust-portal PDFs are watermarked per download** with the downloader's email address
and a timestamp on every page. Get clean copies before submission, or confirm with the
user that shipping watermarked copies is acceptable.

**A whitepaper is not a conformity assessment.** Position papers argue a stance; they do
not evidence compliance. Where a criterion demands evidence and only a position paper
exists, the criterion stays failed. Do not let a persuasive document convert a
documented gap into a claimed compliance — and check publication dates, since
regulatory papers go stale and a wrong date in an attached document is a soft target.
